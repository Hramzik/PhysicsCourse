### Параметры системы
При параметризации m, k, L, mu решение считается долго, поэтому считаем
m = 1
k = 1
L = 1
mu = 70.

Начальные условия
x0, y0
vx0, vy0

Симулировать будем при
x0 = 1, y0 = 1 vx0 = 1, vy0 = 0

### Геометрия
Стена 1: y = 0
Стена 2: y = tg70 * x

Точки крепления
A(ctg 35, 0) - на стене 1
B(ctg 35 - sin 70, 1 + 1 * cos 70) - на стене 2
O(ctg 35, 1) - положение равновесия

### Уравнения
l1 = sqrt((x - Ax)^2 + y^2)
l2 = sqrt((x - Bx)^2 + (y - By)^2)

F1x = (L - l1) * (x - Ax)/l1
F1y = (L - l1) * y       /l1

F2x = (L - l2) * (x - Bx)/l2
F2y = (L - l2) * (y - By)/l2

x''=F1x+F2x
y''=F1y+F2y
