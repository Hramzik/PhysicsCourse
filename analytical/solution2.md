### Параметры системы
m, mu (угол)
k1, k2, k3
L1, L2, L3

Начальные условия
x0, y0
vx0, vy0

### Геометрия
Стена 1: y = 0
Стена 2: x = 0
Стена 3: перпендикулярна пружине 3

Точки крепления
A(L2, 0) - на стене 1
B(0, L1) - на стене 2
C(L2 + L3sinmu, L1 + L3*cosmu) - на стене 3
O(L2, L1) - положение равновесия

### Уравнения
l1 = sqrt((x - L2)^2 + y^2)
l2 = sqrt(x^2 + (y - L1)^2)
l3 = sqrt((x - Cx)^2 + (y - Cy)^2)

F1x = k1*(L1 - l1) * (x - L2)/l1
F1y = k1*(L1 - l1) * y       /l1

F2x = k2*(L2 - l2) * x       /l2
F2y = k2*(L2 - l2) * (y - L1)/l2

F3x = k3*(L3 - l3) * (x - Cx)/l3
F3y = k3*(L3 - l3) * (y - Cy)/l3

m*x''=F1x+F2x+F3x
m*y''=F1y+F2y+F3y
